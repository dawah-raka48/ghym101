# نظام تحويلات رسوم طلاب مركز غيم

تطبيق عربي RTL لإدخال تحويلات رسوم الطلاب ومراجعتها وتوثيق أرقام الفواتير الصادرة من النظام المحاسبي الخارجي.

## مكونات المشروع
- `index.html` و`style.css` و`app.js`: واجهة GitHub Pages.
- `Code.gs`: خادم Google Apps Script (انسخ محتواه إلى مشروع Apps Script مستقل).
- Google Sheets: سجل التحويلات والمستخدمين والإعدادات وسجل التدقيق.
- Google Drive: حفظ إيصالات PDF في مجلد خاص غير عام.

## نشر الواجهة
المسار المقترح بعد تفعيل GitHub Pages للمستودع:
`https://dawah-raka48.github.io/ghym101/transfers/`

## إعداد الخادم وقاعدة البيانات
1. أنشئ Google Sheet مخصصًا لهذا النظام، ولا تجعل مشاركته عامة.
2. من Extensions > Apps Script افتح مشروعًا مرتبطًا بالجدول، والصق ملف `Code.gs`.
3. شغّل الدالة `setup()` من المحرر ووافق على الصلاحيات المطلوبة. تنشئ الدالة الأوراق ومجلد إيصالات خاصًا.
4. في ورقة `Users` أضف مستخدمين برموز دخول قوية وفريدة: `userId | name | accessCode | role | active`. استخدم `ACCOUNTANT` للمحاسب العام و`DATA_ENTRY` لموظف الإدخال. لا تستخدم رموزًا افتراضية سهلة ولا ترسل الرموز في مجموعات.
5. انشر Apps Script من Deploy > New deployment > Web app. اختر Execute as: Me. وصول الويب يجب أن يكون وفق سياسة حساب Google/Workspace؛ إن اخترت Anyone، فسيكون رابط الخدمة عامًا لكن العمليات محمية بالرمز والجلسة على الخادم. لا تضع أي أسرار في GitHub.
6. انسخ رابط النشر المنتهي بـ `/exec` وضعه في أعلى `app.js` مكان `API_URL`.
7. فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main > /(root).

## سير العمل
- موظف الإدخال يرفع اسم الطالب، المبلغ، الفترة، ملاحظات، وإيصال PDF.
- الحالة الأولى `PENDING` (قيد المراجعة)، وتظهر للمحاسب.
- المحاسب يؤكد التحويل ثم يسجل رقم الفاتورة من النظام المحاسبي الخارجي ويؤكد اكتمالها.
- يمكن إعادة العملية للموظف للتصحيح مع سبب موثق.
- التقارير قابلة للتصدير بصيغة CSV التي يفتحها Excel.

## ملاحظات أمنية وتشغيلية
- لا تشارك Google Sheet أو مجلد الإيصالات على وضع Public.
- إيصالات PDF محفوظة في Drive الخاص، ولا تُعرض إلا عبر إجراء خادمي يتحقق من جلسة المستخدم وصلاحياته.
- رموز الدخول مخزنة في ورقة Users؛ قيّد الوصول إلى ملف Google Sheet ومشروع Apps Script للمسؤولين فقط.
- النظام يسجل أحداث المراجعة في AuditLog.
- هذا إصدار أولي يحتاج نشر Apps Script وربطه واختباره بحسابك قبل استخدامه في عمليات مالية حقيقية. لا يحتوي على بيانات طلاب حقيقية أو بيانات دخول افتراضية.
- راجع سياسة المؤسسة ومتطلبات حماية البيانات قبل اختيار إعداد وصول Web App.
