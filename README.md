# نظام إيرادات مركز غيم

واجهة عربية RTL متوافقة مع الجوال والكمبيوتر، مستضافة على GitHub Pages، مع Google Sheets كقاعدة بيانات وGoogle Apps Script كواجهة API.

## الملفات
- `index.html` و`style.css` و`app.js`: واجهة تسجيل الدخول ولوحات المدير والموظف.
- `display.html`: شاشة عرض إجماليات فقط.
- `Code.gs`: كود الخادم وقواعد الصلاحيات.
- `Reports` تشمل إجمالي الإيرادات وعدد الطلاب/الفواتير وطرق الدفع: الشبكة، التحويل، قرة، نقدًا.

## إعداد قاعدة البيانات
1. أنشئ Google Sheet جديدًا مخصصًا للنظام.
2. من **Extensions → Apps Script** افتح محرر Apps Script.
3. استبدل محتوى `Code.gs` بالكود الموجود بهذا المستودع.
4. اختر الدالة `setup` ثم اضغط Run ووافق على الصلاحيات. ستُنشأ أوراق Users وReports وSessions وSettings وAudit.
5. شغّل `setupAdmin` من المحرر لإنشاء حساب المدير. استخدم كلمة مرور قوية لا تقل عن 12 حرفًا، ولا تضع كلمة المرور في ملفات GitHub.
6. من **Project Settings** اضبط المنطقة الزمنية إلى `Asia/Riyadh`.

## نشر API
1. من Apps Script اختر **Deploy → New deployment → Web app**.
2. اجعل التنفيذ **Execute as: Me**. يجب ضبط الوصول بما يسمح للواجهة بالاتصال وفق سياسات حساب Google/Workspace. لا تنشر بيانات الشيت مباشرة ولا تجعل الشيت نفسه عامًا.
3. انسخ رابط Web app الذي ينتهي بـ `/exec`.
4. ضع الرابط في المتغير `API_URL` أعلى `app.js`، وكذلك في متغير `API_URL` داخل `display.html`.
5. انشر التعديلات على GitHub.

## رابط شاشة العرض الخاصة
بعد إعداد النظام، افتح رابط Web app وأضف مفتاح العرض الذي أنشأته دالة `setup` في ورقة Settings:
`YOUR_APPS_SCRIPT_URL?display=DISPLAY_KEY_VALUE`
هذا الرابط يعرض ملخص الإيرادات فقط عبر Apps Script، لكنه سرّ رابط وليس نظام دخول قويًا؛ شاركه فقط مع شاشة المركز، ويمكن تدويره بتغيير قيمة DISPLAY_KEY في ورقة Settings. لا تضعه في مكان عام أو في ملفات المستودع. صفحة `display.html` حاليًا تعرض البيانات عبر طلب `publicDisplay` لتسهيل ربط الشاشة؛ قبل نشرها في مكان عام، يلزم تعديلها لاستخدام مفتاح العرض عبر آلية لا تكشف المفتاح في المستودع.

## نشر GitHub Pages
1. افتح Settings للمستودع `ghym101`.
2. من Pages اختر **Deploy from a branch**، الفرع `main` والمجلد `/(root)`، ثم Save.
3. بعد اكتمال النشر سيكون الرابط عادةً: `https://dawah-raka48.github.io/ghym101/`.

## ملاحظات مهمة قبل الاستخدام الفعلي
- هذا إصدار أولي؛ يجب اختبار الاتصال في حساب Google المستخدم قبل تسجيل بيانات حقيقية.
- الواجهة تقبل رابط PDF على Google Drive؛ رفع الملف نفسه لم يُفعّل بعد. شارك مجلد التقارير مع الأشخاص المخولين فقط.
- كل موظف يمكنه حفظ تقرير واحد في اليوم. عند وجود خطأ، يستطيع المدير حذف التقرير ليُعاد إدخاله. الحذف مسجل في سجل التدقيق.
- الإجماليات تتحدث مباشرة بعد حفظ التقرير. لا توجد خطوة اعتماد مسبق.
- لا تضف كلمات مرور أو مفاتيح خاصة أو بيانات دخول إلى ملفات GitHub.
- شاشة العرض الحالية تستخدم إجراء تجميعي عام لتحديث الشاشة؛ قبل وضعها على شبكة عامة، يجب حماية طلب القراءة بمفتاح عرض خاص على الخادم، وعدم إرجاع بيانات الموظفين أو التقارير التفصيلية.
